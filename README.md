# SignBridgeNative


- VI: Đây là phiên bản build hoàn toàn với `Kotlin - M3 - Jetpack Compose`. Mang đến hiệu suất vượt trội hơn so với app React Native. Ngoài ra ứng dụng cung cấp thêm tính năng nạp models từ các bản release. Đây vẫn chỉ là phiên bản thử nghiệm!!!
- EN: This version is built entirely using `Kotlin, M3 (Material 3), and Jetpack Compose`, delivering superior performance compared to the React Native app. Additionally, the application includes a feature that allows for loading models from various releases. Please note that this is still an experimental version!!!
